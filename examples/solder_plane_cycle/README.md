# Plane-strain SnPbAg solder cycle

This runnable example calls the public
`eda_multiphysics.solder_joint.solder_joint_cycle` API. It solves a generated
0.1 mm × 0.1 mm plane-strain block with a 3 × 2 Quad4 mesh and the checked-in
62Sn36Pb2Ag Anand parameter set. The bottom edge is fixed; the top edge follows
an idealized CTE-mismatch displacement while the lateral edges remain
traction-free.

## Inputs and configuration

- temperature history: one endpoint-inclusive −40 → 125 → −40 °C cycle;
- period and increments: 1600 s and 12 equal increments;
- CTE mismatch: 20 × 10⁻⁶ K⁻¹;
- distance-to-neutral-point ratio: `L_D / h = 6`;
- generated geometry: 0.1 mm square, six Quad4 elements; and
- material: Cheng/Wang et al. 62Sn36Pb2Ag Anand constants, plus representative
  project-model elastic inputs `E = 30,000 MPa` and `ν = 0.40`.

Run from the repository root after `./setup.sh`:

```bash
python examples/solder_plane_cycle/run.py
python examples/solder_plane_cycle/run.py --check
```

Both commands write deterministic JSON only to standard output and do not
create source-tree files. `--check` reads `expected_results.json`, compares the
selected numerical metrics, verifies that the largest reported residual remains
inside Core's acceptance limit, and exits nonzero on a mismatch.

## Output meaning

`cycle_dW_MPa` is the increment-summed, equal-volume mean of Gauss-point
inelastic energy-density increments over the top element layer. In these units,
1 MPa equals 1 MJ/m³. The current recorded value is approximately 0.331884 MPa.
The solver fields report the largest iteration count and residual measures over
the cold initialization plus the cycle. A residual fraction below one means the
increment met Core's existing acceptance rule. State advances once only after
an increment is accepted.

The runner is an **example**, while `expected_results.json` supplies a small
numerical regression check. It is not a measured benchmark or a solver-speed
benchmark.

## Provenance and references

The mesh and load history are generated by this project. The Anand model and
62Sn36Pb2Ag constants follow Cheng, Wang, Chen, Wilde, and Becker,
“Viscoplastic Anand model for solder alloys and its application,” *Soldering &
Surface Mount Technology* 12(2), 31–36, 2000,
doi:10.1108/09540910010331428. The elastic modulus and Poisson ratio are
separate representative project-model inputs. The implementation checks the
published-model saturation relation and an affine elastic patch before this
cycle in the module-level validation path. See
[`../REFERENCES.md`](../REFERENCES.md) and
[`../../docs/theory.md`](../../docs/theory.md) for the wider evidence map and
equations.

## Limitations

This is an idealized single-cycle block calculation. It does not establish a
stabilized cycle, mesh or load-step convergence, a production package geometry,
crack location, predictive life, or real-package validation. The reported local
energy observable must not be interpreted as a validated package-life result.
